# TQ Desk · 天勤行情工作台

自托管的国内期货行情工作台：品种筛选、实时快照、K 线图表、现货基差、自选行情板。
基于 [TqSdk](https://doc.shinnytech.com/tqsdk/latest/)（免费快期账号）+ [AKShare](https://akshare.akfamily.xyz/)（生意社现货），
单容器部署，浏览器即用，个人轻量使用免费。

## 功能

- **品种浏览**：六大交易所全品种，中文名/代码/交易所多维搜索筛选
- **合约快照**：最新价、五档、涨跌停、量仓等，支持主力连续与具体合约切换
- **K 线图表**：1分～日线六档周期，手绘蜡烛图（进行中 K 线弱化标记），明细表点击按自定义模板复制
- **现货基差**：生意社现期表匹配（合约代码硬校验），现货价 / 主力基差 / 基差率
- **自选合约**：心形收藏、拖拽排序、列表实时价格（红涨绿跌）
- **稳定性**：断线自动重连、任务最新优先、K 线热订阅、设置持久化

## 快速开始

### Docker（推荐）

```bash
docker run -d --name tq-desk -p 8848:8848 \
  -e TZ=Asia/Shanghai \
  -e TQ_USER=你的快期账号 \      # 可选，配置后免登录
  -e TQ_PASS=你的快期密码 \
  <your-dockerhub-username>/tq-desk:latest
